FOR RITTHIKA SURYA NARAYANAN — A LITTLE SORRY

Open index.html directly in any modern browser. No install, build, server, or internet is required.

CUSTOMIZE
Edit CONFIG at the top of script.js:
- girlfriendName: name throughout the experience
- apologyText and finalApology: letter and final message (one array item per paragraph)
- memories: captions, photo paths, accessible descriptions, and placeholder motifs
- coupons: titles, icons, descriptions; keep each id unique and stable
- musicPath: music file location

Add your own photos to assets/photo1.jpg through assets/photo5.jpg.
Add music you have permission to use as assets/romantic-music.mp3.
Missing media are intentionally not replaced with fake JPG/MP3 files. Illustrated placeholders appear until photos are added. Music gracefully becomes unavailable if absent.

Change the palette and spacing in the :root variables in style.css.
Coupon redemptions are stored only in this browser/device; no message is sent to anyone. If storage is blocked, redemption still works for the visit.
Music always waits for a click. The heart meter does not gate content. Both final answers remain available.
